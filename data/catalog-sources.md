# Headphone catalog: sources

Generated by `scripts/build_catalog.py` from AutoEq 7ae0f56d5307 (2025-07-20). Do not edit by hand.

- **6,813 measurements** of **4,859 distinct AutoEq names** (3,503 brand + model groups, variants such as pads or ANC modes folded together), from 22 sources.

- Curves: 241 points, 1/24 octave from 20 Hz, centi-dB, delta + varint coded. `data/catalog.bin` is 2,300,801 bytes.

## Targets and default bass shelf

Every measurement gets the target AutoEq's web app recommends for its source, form and rig, and that target's default bass shelf (low shelf at 105 Hz, Q 0.7). Both come from `dbtools/create_webapp_data.py` (`recommended`, `bassBoost`), which `ApiClient.fetchTargets` in autoeq.app uses to pick the target when a headphone is selected. The same gains are in `autoeq/constants.py` (`DEFAULT_BASS_BOOST_GAINS`).

Cross-check against AutoEq's precomputed `results/` (target column of one result per source folder, fitted against every target and bass gain): the over-ear and in-ear folders match this table, e.g. oratory1990 Beyerdynamic DT 770 Pro = `Harman over-ear 2018 without bass` + 6.0 dB, except HypetheSonics over-ear (computed with about +10 dB on LMG 5128). Earbud results are inconsistent there (several sources were batch-processed with 0 dB of bass, Regan Cipher earbuds with the Harman over-ear target). The web-app table above is what autoeq.app uses today and is what this catalog follows. Flatline's own "Harman" preset (+6.5 dB) is half a dB above AutoEq's +6 dB.

## Left out

- DHRME over-ear: 1 measurement(s), no target recommended by AutoEq for this group (AutoEq computes no result for it either).
- `Auriculares Argentina/Kiwi Ears KE4` filed as over-ear: same source and name also filed under another form (a mislabelled channel in the source's name index); the form most sources use is kept.
- crinacle: AutoEq no longer ships crinacle's raw measurements (`measurements/crinacle` only keeps its name index), so none are included.
