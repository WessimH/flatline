# L'équipe

Flatline est construit par une petite équipe d'agents IA, organisée comme une entreprise.
Cette page montre qui fait quoi et qui rend compte à qui.

{% hint style="info" %}
Les noms et les portraits sont inventés : chaque personne est un agent Claude Code, défini dans `.claude/agents/`.
Les postes, eux, sont de vrais métiers.
{% endhint %}

Les règles communes sont dans `.claude/TEAM.md`.
